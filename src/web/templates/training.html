📐 5. The Mathematics of LoRA Decomposition

Matrix Algebra

Low-Rank Intrinsic Dimension Factorization

During fine-tuning, dense weight updates $\Delta W \in \mathbb{R}^{d \times k}$ reside on a low intrinsic manifold. LoRA factorizes this into two small rank-$r$ matrices:

$$h = W_0 x + \Delta W x = W_0 x + \frac{\alpha}{r} (B \cdot A) x$$
  • $W_0 \in \mathbb{R}^{d \times k}$: Frozen base model weights.
  • $A \in \mathbb{R}^{r \times k}$: Down-projection matrix initialized with random Gaussian $\mathcal{N}(0, \sigma^2)$.
  • $B \in \mathbb{R}^{d \times r}$: Up-projection matrix initialized to 0 ($\Delta W = 0$ at start).
  • $\frac{\alpha}{r}$: Scaling constant balancing base knowledge and adapter adjustments.

🧮 6. NF4 (NormalFloat4) Quantization Mechanics

Information Theory

Pre-trained neural weights follow a Gaussian distribution $\mathcal{N}(0, \sigma^2)$. Uniform 4-bit integer quantization causes significant errors near zero. NF4 constructs 16 information-theoretically optimal quantiles with equal expected information density.

Functional State Management with JAX & Flax NNX

Pure functions, XLA JIT Compilation, and Immutable TrainState for TPU Pod scaling.

Google JAX / TPU Native 
import jax
import jax.numpy as jnp
from flax import nnx
from flax.training.train_state import TrainState
import optax

# Functional LoRA Linear Layer in Flax NNX
class LoRALinearFlax(nnx.Module):
    def __init__(self, in_features: int, out_features: int, rank: int = 8, alpha: float = 16.0, rngs: nnx.Rngs = None):
        self.base_w = nnx.Param(jax.random.normal(rngs.params(), (in_features, out_features)))
        self.lora_a = nnx.Param(jax.random.normal(rngs.params(), (in_features, rank)) * 0.01)
        self.lora_b = nnx.Param(jnp.zeros((rank, out_features)))
        self.scaling = alpha / rank

    def __call__(self, x: jax.Array) -> jax.Array:
        base_out = jnp.dot(x, self.base_w.value)
        lora_out = jnp.dot(jnp.dot(x, self.lora_a.value), self.lora_b.value) * self.scaling
        return base_out + lora_out
